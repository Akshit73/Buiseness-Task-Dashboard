# Business Task & Performance Dashboard

A responsive web application for employee task management and performance tracking. The dashboard helps manage tasks, monitor employee performance, track deadlines, and visualize completion rates through interactive charts.

## Features

* User Login & Logout
* Add, Edit, and Delete Tasks
* Task Completion Tracking
* Employee Search Functionality
* Priority Management (High, Medium, Low)
* Overdue Task Highlighting
* Performance Dashboard
* Interactive Charts using Chart.js
* Local Storage Data Persistence
* Responsive Design

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Chart.js
* Local Storage
